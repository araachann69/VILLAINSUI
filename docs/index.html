Why VILLAINS UI?

🎨

Premium Dark Red

Carefully crafted dark red color palette with crimson accents, glow effects, and glass-morphism surfaces.

✨

Smooth Animations

Spring-based tweens, scale transitions, ripple effects, pulse glows, and slide-in notifications.

🧩

Rich Elements

Button, Toggle, Slider, Input, Dropdown, Keybind, Paragraph, Section, Divider, and more.

📦

Loadstring Ready

Single-file distribution via GitHub raw. No dependencies. Works with all major executors.

🪟

Window System

Draggable windows, sidebar tabs, tags, open button, minimize/close controls, and popup dialogs.

📖

Easy API

Familiar API design similar to WindUI. Chain elements on tabs with intuitive method calls.
