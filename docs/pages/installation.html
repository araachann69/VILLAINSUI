Installation

Load VILLAINS UI Library via loadstring from GitHub.

Loadstring (Recommended)

Upload the repository to GitHub, then use this code in your Roblox executor:

Lua 
local VillainsUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/YOUR_USERNAME/VILLAINS-UI-LIBRARY/main/dist/VillainsUI.lua"
))()

Run Example

Try the full demo with all UI elements:

Lua 
loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/YOUR_USERNAME/VILLAINS-UI-LIBRARY/main/example.lua"
))()

Quick Start

Lua 
local VillainsUI = loadstring(game:HttpGet("YOUR_URL/dist/VillainsUI.lua"))()

local Window = VillainsUI:CreateWindow({
    Title = "My Hub",
    Author = "Script Hub",
    Icon = "☠",
})

local Tab = Window:Tab({ Title = "Main", Icon = "⚔" })

Tab:Toggle({
    Title = "Auto Farm",
    Default = false,
    Callback = function(value)
        print("Toggle:", value)
    end,
})

VillainsUI:Notify({
    Title = "Loaded!",
    Content = "VILLAINS UI is ready.",
    Duration = 3,
})

Deploy Documentation to Vercel

  1. Push this repository to GitHub
  2. Go to vercel.com and import the repo
  3. Set the root directory to docs
  4. Deploy — your docs will be live!

Requirements

  • Roblox executor with loadstring and game:HttpGet
  • Supports CoreGui / gethui parent
  • Works with Synapse, Fluxus, Delta, Solara, and others
