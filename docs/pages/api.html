Animation System

Built-in animations using TweenService with Quint and Back easing:

  • Window open — Scale + fade with spring bounce
  • Tab switch — Slide transition with color fade
  • Toggle — Spring knob animation
  • Button — Ripple effect on click
  • Notification — Slide in from right
  • Open button — Pulse glow loop
  • Hover — Smooth color/transparency transition
