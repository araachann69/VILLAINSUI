Window

Create and customize the main UI window.

CreateWindow

Lua 
local Window = VillainsUI:CreateWindow({
    Title = "VILLAINS Hub",
    Author = "Premium Script Hub",
    Icon = "☠",
    Folder = "VillainsHub",
    Size = UDim2.fromOffset(600, 500),
    SideBarWidth = 210,
    OpenButton = {
        Title = "Open UI",
        Enabled = true,
        CornerRadius = UDim.new(1, 0),
        StrokeThickness = 2,
        Color = ColorSequence.new(
            Color3.fromHex("#8B0000"),
            Color3.fromHex("#DC143C")
        ),
    },
})

Parameters

ParameterTypeDescription
TitlestringWindow title displayed in topbar
AuthorstringSubtitle text below title
IconstringEmoji, rbxassetid://, or image URL
FolderstringConfig folder name (for future config save)
SizeUDim2Window size (default: 580x480)
SideBarWidthnumberSidebar width in pixels (default: 200)
OpenButtontableFloating button to toggle window visibility

Tab

Lua 
local Tab = Window:Tab({
    Title = "Main",
    Icon = "⚔",
    IconColor = Color3.fromHex("#DC143C"),
})

Tag

Add version or status tags to the window header area.

Lua 
Window:Tag({
    Title = "v1.0.0",
    Icon = "⚡",
    Color = Color3.fromHex("#DC143C"),
    Border = true,
})

Window Methods

MethodDescription
Window:Tab(config)Create a new sidebar tab
Window:Tag(config)Add a tag badge to the header
Window:Toggle()Show/hide the window
Window:SetVisible(bool)Set window visibility
Window:Destroy()Destroy window and open button

Notify

Lua 
VillainsUI:Notify({
    Title = "Success",
    Content = "Action completed!",
    Icon = "✓",
    Type = "Success", -- Success | Warning | Error | Info
    Duration = 4,
})

Popup & Dialog

Lua 
VillainsUI:Popup({
    Title = "Confirm Action",
    Icon = "⚠",
    Content = "Are you sure you want to proceed?",
    Buttons = {
        { Title = "Cancel", Variant = "Secondary" },
        { Title = "Confirm", Variant = "Primary", Callback = function()
            print("Confirmed!")
        end },
    },
})
